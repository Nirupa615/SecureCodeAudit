# 🔐 SecureCode Audit

A Python-based cybersecurity project that demonstrates secure coding practices by identifying and fixing common vulnerabilities in a user authentication system.

## 📌 Project Overview

SecureCode Audit is a mini cybersecurity project focused on reviewing an insecure Python authentication system and implementing security best practices. The project demonstrates how common authentication vulnerabilities can be mitigated using secure coding techniques.

The application provides a simple login system with enhanced security mechanisms such as password hashing, password strength validation, brute-force protection, and input validation.

---

## 🎯 Objectives

- Identify security flaws in an authentication system.
- Apply secure coding principles.
- Prevent common authentication attacks.
- Improve password security.
- Demonstrate secure software development practices.

---

## ✨ Features

- 🔒 Secure password hashing using SHA-256
- 🔑 Password strength validation
- 🚫 Brute-force attack protection
- ✅ Secure user authentication
- 🛡️ Input validation
- 📋 Simple and easy-to-understand implementation
